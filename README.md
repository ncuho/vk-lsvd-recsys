# Влияние контентных эмбеддингов на рекомендации

Учебный проект: исследование того, как добавление контентных признаков
(эмбеддингов и метаданных объектов) влияет на качество рекомендаций.

## Данные

Открытый датасет коротких видео **VK-LSVD**
(https://huggingface.co/datasets/deepvk/VK-LSVD).

Используется репрезентативная подвыборка `ur0.01_ir0.01`:

| | |
|---|---|
| пользователей | 90 178 |
| объектов | 125 018 |
| взаимодействий (train) | 3 720 328 |
| плотность | 0.033% |

Разбиение по неделям (Global Temporal Split): недели 0–24 — обучение, 25 — валидация,
26 — тест. Контентные признаки: 64-мерные эмбеддинги объектов (`item_embeddings.npz`)
и метаданные (`author_id`, `duration`).

## Модели

| Модель | Описание |
|--------|----------|
| Popularity | неперсонализированный базовый уровень (популярность объекта) |
| UserKNN | коллаборативная фильтрация по похожим пользователям |
| ItemKNN | коллаборативная фильтрация по похожим объектам |
| MF (BPR) | матричная факторизация с байесовским персонализированным ранжированием |
| ContentProfile (embeddings) | профиль пользователя по 64-мерным эмбеддингам |
| ContentProfile (metadata) | профиль пользователя по author_id и duration |
| Hybrid | взвешенная комбинация коллаборативного и контентного скора |

## Метрики

Precision@10, Recall@10, NDCG@10, MAP@10 на задаче ранжирования кандидатов
(положительные примеры из тестовой недели + смешанные негативные кандидаты:
50 популярных + 50 случайных).

## Результаты (тест, NDCG@10 — основная метрика)

| Модель | Precision@10 | Recall@10 | NDCG@10 | MAP@10 |
|--------|-------------:|----------:|--------:|-------:|
| Popularity | 0.0001 | 0.0002 | 0.0001 | 0.0000 |
| UserKNN | 0.0208 | 0.0875 | 0.0527 | 0.0312 |
| ItemKNN | 0.0331 | 0.1327 | **0.1064** | 0.0783 |
| MF_BPR | 0.0038 | 0.0169 | 0.0109 | 0.0065 |
| **ContentProfile (embeddings)** | **0.0688** | **0.2021** | **0.1446** | **0.0864** |
| ContentProfile (metadata) | 0.0426 | 0.1193 | 0.0807 | 0.0425 |
| Hybrid ItemKNN+emb | 0.0334 | 0.1161 | 0.0906 | 0.0620 |
| Hybrid ItemKNN+meta | 0.0290 | 0.1000 | 0.0789 | 0.0537 |
| Hybrid MF+emb | 0.0066 | 0.0263 | 0.0156 | 0.0085 |

**Вывод:** контентные эмбеддинги (NDCG@10 = 0.1446) превосходят лучшую
коллаборативную модель ItemKNN (0.1064) на 36%, а также заметно сильнее простых
метаданных (0.0807).

## Запуск

```bash
pip install -r requirements.txt
# скачать подвыборку ur0.01_ir0.01 в data/interactions/ и metadata/ в data/metadata/
python main.py
```

Результаты сохраняются в `data/results.csv`.

## Структура

- `main.py` — весь код: загрузка данных, модели, метрики, запуск;
- `data/` — скачанный датасет (в git не включён).
